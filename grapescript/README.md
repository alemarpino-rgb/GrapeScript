# Estensione Grapescript per VS code

Ecco l'estensione per vscode per il mio linguaggio. Aumenta la leggibilità, l'ho fatta perchè non riuscivo praticamente più a leggere cosa srivevo. :)

## Come installare

Digita nel prompt dei comandi

'''
code --install-extension grapescript-0.2.0.vsix
'''

Aggiorna la pagina ed ecco che ogni file .gs sarà colorato!

**Ecco fatto!**
